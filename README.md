# Trade Analysis Report

楽天証券・SBI証券の取引履歴CSVから、確定損益と取引成績を分析するローカルWebアプリです。日本語・英語切り替え、スマートフォン・タブレット・PCの画面幅に対応しています。

## 起動

Node.js 22.13以上を使用します。

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

## GitHub Pages

`main` ブランチへの push で GitHub Pages 用の静的サイトを自動デプロイします。GitHub のリポジトリ設定で、Pages の公開元を **GitHub Actions** に設定してください。

表示されたURLを開き、「CSVを読み込む」から楽天証券の取引履歴CSV（`tradehistory(JP)_*.csv`）またはSBI証券の取引履歴CSV（`SaveFile_*.csv`）を選択してください。CSVをブラウザ内でShift-JISまたはUTF-8として読み込みます。取引データのサーバー送信・保存はありません。再読み込み後はCSVを再選択してください。元CSVはバックアップとして保持してください。

## 機能

- 期間・銘柄・ロング／ショートで連動するフィルター
- 期間確定損益、累積確定損益、勝率ドーナツ、PF
- 日別損益の合計棒グラフ／銘柄別積み上げ棒グラフの切り替え。正負はゼロ線の上下に積み上げ
- ロング／ショート別の損益・勝率・利益率・平均利益／損失・ペイオフレシオ
- 銘柄別損益ランキングは、両方・ロング・ショートで切り替え可能。銘柄フィルターへドリルダウン
- 月曜始まりの週次、および暦月の月次サマリー
- 元CSV行番号付き決済明細。横長表はモバイルで表内スクロール

## 集計仕様

楽天証券の取引履歴では `信用返済` のCSV明細を1件として集計し、`売埋`がロング、`買埋`がショートです。SBI証券の取引履歴では `信用返済売` がロング、`信用返済買` がショートです。SBI証券の現物・投信・現引などは集計対象外です。

純損益は楽天証券の取引履歴にある `受渡金額［円］`、SBI証券の取引履歴にある `受渡金額/決済損益` を採用します。費用の重複控除はしません。楽天証券で建約定日・建単価・受渡金額が未確定の信用返済明細、およびSBI証券で決済損益が `--` の信用返済明細は、確定損益レポートから除外し件数を表示します。楽天CSVの当日未確定明細は、同一CSV内の信用新規を銘柄・売買方向別にFIFOで対応付けられる場合のみ、メイン集計へは加えない「当日概算損益」として別表示します。証券会社の建玉指定とは異なる場合があるため、概算値は確定損益・勝率・週次月次サマリーには含めません。SBI証券の取引履歴CSVには建単価がないため、利益率と建単価は表示できません。

- 勝率 = 正の純損益明細数 / 全決済明細数（引き分け含む）
- 利益率 = 純損益合計 / Σ（建単価 × 決済数量）。建約定金額に対する率で、証拠金や口座資産に対する率ではありません
- PF = 利益明細の利益合計 / 損失明細の損失絶対値合計。利益があり損失ゼロなら∞、空データ等は未算出
- ペイオフレシオ = 平均利益 / 平均損失絶対値。両方が存在するときのみ表示
- 累積損益は選択期間内のみ。口座総資産、入出金、含み損益は含みません
- 期間は約定日基準。取引のない日は描画点なし。週・月が選択期間をまたぐ場合は選択内のみ集計
- 約定明細をまとめた「一連のトレード」の識別、分足や株価ローソク足はこのCSV単体では扱いません

## 構成

`app/page.tsx`: 分析画面とブラウザ内ファイル読込。`lib/analysis.ts`: CSV解析と純粋集計関数。`app/globals.css`: モバイル対応の紺色テーマ。Vinext / React / Rechartsと既存Shadcn部品で構成しています。外部価格APIや口座APIは不要です。

## 検証

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

実データ照合は元CSVをコピーせずパス指定で実行できます。

```sh
TRADE_CSV_TEST_PATH='/path/to/rakuten-tradehistory.csv' npm test
SBI_CSV_TEST_PATH='/path/to/sbi-tradehistory.csv' npm test
```

検証対象CSVの既知値: 1,664元明細、840決済明細、502勝327敗11分、純損益232,838円（ロング −61,608円、ショート294,446円）。新しいCSVでは固定値照合テストを実行せず、通常テストと実際の口座明細で検証してください。

個人CSVは公開用フォルダやGitに追加しないでください。アプリはローカル利用向けで、公開デプロイは行っていません。

Lintはアプリ・集計コードを対象とし、生成された未変更のShadcn部品と `hooks/use-mobile.ts` を除外しています。モバイル向けレイアウトを実装していますが、iOS / Android実機での操作確認は未実施です。
