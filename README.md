# Trade Analysis Report

日本株の `tradehistory(JP)` CSVから、確定損益と取引成績を分析するローカルWebアプリです。日本語・英語切り替え、スマートフォン・タブレット・PCの画面幅に対応しています。

## 起動

Node.js 22.13以上を使用します。

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

表示されたURLを開き、「CSVを読み込む」から `tradehistory(JP)_20260912.csv` を選択してください。CSVをブラウザ内でShift-JISまたはUTF-8として読み込みます。取引データのサーバー送信・保存はありません。再読み込み後はCSVを再選択してください。元CSVはバックアップとして保持してください。

## 機能

- 期間・銘柄・ロング／ショートで連動するフィルター
- 期間確定損益、累積確定損益、勝率ドーナツ、PF
- 日別損益の合計棒グラフ／銘柄別積み上げ棒グラフの切り替え。正負はゼロ線の上下に積み上げ
- ロング／ショート別の損益・勝率・利益率・平均利益／損失・ペイオフレシオ
- 銘柄別損益ランキングと銘柄フィルターへのドリルダウン
- 月曜始まりの週次、および暦月の月次サマリー
- 元CSV行番号付き決済明細。横長表はモバイルで表内スクロール

## 集計仕様

`信用返済` のCSV明細を1件として集計し、信用新規は勝率の分母に含めません。`売埋`がロング、`買埋`がショートです。現物など他の取引区分は誤集計防止のためエラーにします。

純損益は `受渡金額［円］` を採用します。費用の重複控除をしません。受渡金額が `-` の場合は建値と決済価格が一致し、手数料等も明示的にゼロの場合に限り0円とします。それ以外の未確定金額・不正列・不正日付は読込エラーになります。

- 勝率 = 正の純損益明細数 / 全決済明細数（引き分け含む）
- 利益率 = 純損益合計 / Σ（建単価 × 決済数量）。建約定金額に対する率で、証拠金や口座資産に対する率ではありません
- PF = 利益明細の利益合計 / 損失明細の損失絶対値合計。利益があり損失ゼロなら∞、空データ等は未算出
- ペイオフレシオ = 平均利益 / 平均損失絶対値。両方が存在するときのみ表示
- 累積損益は選択期間内のみ。口座総資産、入出金、含み損益は含みません
- 期間は約定日基準。取引のない日は描画点なし。週・月が選択期間をまたぐ場合は選択内のみ集計
- 約定明細をまとめた「一連のトレード」の識別、分足や株価ローソク足はこのCSV単体では扱いません

## 構成

`app/page.tsx`: 分析画面とブラウザ内ファイル読込。`lib/analysis.ts`: CSV解析と純粋集計関数。`app/globals.css`: モバイル対応の紺色テーマ。Vinext / React / Rechartsと既存Shadcn部品で構成しています。外部価格APIや口座APIは不要です。

## 検証

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

実データ照合は元CSVをコピーせずパス指定で実行できます。

```sh
TRADE_CSV_TEST_PATH='/path/to/tradehistory(JP)_20260912.csv' npm test
```

検証対象CSVの既知値: 1,664元明細、840決済明細、502勝327敗11分、純損益232,838円（ロング −61,608円、ショート294,446円）。新しいCSVでは固定値照合テストを実行せず、通常テストと実際の口座明細で検証してください。

個人CSVは公開用フォルダやGitに追加しないでください。アプリはローカル利用向けで、公開デプロイは行っていません。

Lintはアプリ・集計コードを対象とし、生成された未変更のShadcn部品と `hooks/use-mobile.ts` を除外しています。モバイル向けレイアウトを実装していますが、iOS / Android実機での操作確認は未実施です。
